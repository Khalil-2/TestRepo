We are committed to making this project accessible to everyone. As we add features, we will ensure:

-   **Semantic HTML:** Using proper tags for structure.
-   **ARIA Labels:** Providing context for screen readers on interactive elements.
-   **Color Contrast:** Maintaining high visibility for all text and UI components.
-   **Keyboard Navigation:** Ensuring full functionality without a mouse.
