## 2024-03-31 - Initial Accessible Landing Page
**Learning:** For a clean-slate project, the primary UX win is an accessible index.html with 'Skip to main content' and aria-live. Avoiding inline JS in scripts improves maintainability and security.
**Action:** When initializing a repo, prioritize high-impact accessibility while maintaining a small code footprint (<50 lines).

## 2025-05-14 - Responsive Baseline and Event Handling
**Learning:** In barebones HTML projects, a responsive viewport meta tag is a critical micro-UX improvement for mobile accessibility. Refactoring inline handlers to `addEventListener` aligns with modern standards and improves maintainability.
**Action:** Always include responsive meta tags in initial page setups and prefer modern event listeners over inline attributes.
