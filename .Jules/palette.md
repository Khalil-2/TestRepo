## 2024-03-30 - Accessible Landing Page in Clean-Slate Repo
**Learning:** For a clean-slate project, the primary UX win is implementing an accessible index.html using semantic HTML and 'Skip to main content' links. Complying with WCAG 2.5.3 (Label in Name) ensures the interactive elements are usable for all. Keeping initial setup under the 50-line limit forces high-impact, focused changes.
**Action:** When initializing a repo, prioritize high-impact accessibility features like skip-links and aria-live regions while strictly adhering to line-count constraints.
