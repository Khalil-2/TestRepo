## 2025-03-14 - [Focus on User-Facing Improvements]
**Learning:** In an empty repository, it's better to provide a small, accessible user-facing component than to over-engineer project infrastructure like PR templates or dummy scripts. A real UI element provides immediate value and a concrete example of UX standards.
**Action:** When starting with a clean slate, prioritize a high-impact, accessible landing page or component under 50 lines.
