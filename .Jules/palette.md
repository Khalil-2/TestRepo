## 2024-03-24 - Accessible Feedback in Minimal HTML
**Learning:** In a clean-slate repository without an existing design system, implementing accessible feedback can be achieved using semantic HTML attributes like `hidden` and ARIA roles like `status` or `aria-live="polite"` to ensure screen reader compatibility without needing custom CSS.
**Action:** Use native HTML attributes and ARIA roles for basic interactivity and feedback when custom styling is restricted or unavailable.
