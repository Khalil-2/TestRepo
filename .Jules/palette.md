## 2025-05-15 - Bootstrapping Accessible Defaults in Clean-Slate Repositories
**Learning:** In a completely clean repository where no UI exists, the most impactful "micro-UX" improvement is to provide a semantic and accessible entry point. Using header, main, and footer tags with clear ARIA labels sets a high accessibility standard from the start.
**Action:** When working on a project with no existing UI, prioritize implementing a minimal, accessible index.html that follows semantic HTML principles and includes visible focus states.
