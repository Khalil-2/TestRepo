## 2025-03-27 - [Clean-slate repository UX setup]
**Learning:** In clean-slate repositories without an existing design system, Palette must avoid adding custom CSS and strictly follow the 50-line limit for new files. Semantic HTML and browser-native styling are the preferred ways to ensure accessibility and usability while staying within these constraints.
**Action:** When initializing a project as Palette, focus on minimal, semantic HTML foundations with core accessibility features (e.g., skip-to-content links and ARIA labels) instead of complex visual styling.
