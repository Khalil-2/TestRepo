## 2026-05-18 - Accessible Character Counters
**Learning:** Using `aria-describedby` to link an input field with its character counter provides immediate context for screen reader users without being overly verbose. Returning focus to the input after submission streamlines the "add another" workflow.
**Action:** Always link character counters to inputs using `aria-describedby` and manage focus to maintain the user's flow in utility tasks.
