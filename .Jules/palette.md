## 2024-03-31 - Initial Accessible Landing Page
**Learning:** For a clean-slate project, the primary UX win is an accessible index.html with 'Skip to main content' and aria-live.
**Action:** When initializing a repo, prioritize high-impact accessibility while maintaining a small code footprint (<50 lines).

## 2026-05-24 - Simulated Loading Feedback
**Learning:** Implementing a brief (800ms) simulated loading state manages user expectations for asynchronous-style actions and prevents duplicate submissions.
**Action:** Use disabled states and transitional text (e.g., 'Loading...') for interactive buttons to provide immediate tactile feedback.
